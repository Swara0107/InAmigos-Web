# InAmigos Web

A simple static website for InAmigos showcasing events, contact information, and a homepage.

## Project Structure

- `index.html` - Main landing page
- `events.html` - Events listing page
- `contact.html` - Contact page
- `style.css` - Site styling
- `script.js` - Client-side scripts
- `events/` - Event-related assets or pages
- `photos/` - Image assets

## Usage

1. Open `index.html` in a web browser to view the site.
2. Use the navigation links to visit Events and Contact pages.

## Notes

- This is a static website and does not require a server for basic browsing.
